# Doodlik — проверка перед сборкой (29.09.2026)

Состояние: изменения оставлены в исходном Unity-проекте для ручной проверки. APK и EXE **не собирались**. Проверки выполнялись в отдельной копии `.utmp/MenuValidation-6e879ab6`, чтобы не запускать второй Editor поверх открытого проекта и не менять игровые сохранения.

## Исправлено

- Скафандр полностью перерисован по новому референсу в рисованной стилистике Дудлика. Шлем теперь отдельный аксессуар с открытыми ушами и мордочкой; белый костюм с оранжевой отделкой и четырьмя ботинками — отдельная одежда. Оба элемента примерены на Дудлике и сиамском котике. Размер коллайдера и физика не менялись. Маска гуля слегка поднята, чтобы рот обычного котика не выглядывал над ней.
- Генерация: во время паузы платформы больше не уходят вперёд без соответствующих ловушек. При изменении ширины окна запас дальности для движущейся платформы меняется вместе с её патрулём.
- Редкие бонусы могут оказываться в воздухе только после проверки безопасного пути к ним и обратно на платформу. Если маршрут разрушился, бонус остаётся на платформе. Частота выдачи бонусов не увеличена; монеты остаются независимыми от платформ.
- Кнопка меню пересчитывает отступ после запаздывающего обновления масштаба Canvas при смене ориентации.
- Версия URP в `Packages/manifest.json` согласована с lock-файлом: 17.5.0.
- Действующий промокод убран из Editor-тестов; проверка успешного погашения использует только локальную переменную `DOODLIK_TEST_PROMO_CODE` и не печатает код. Исправлено восстановление пустого набора сцен после автономного теста генерации.

## Что остаётся проверить перед публичной сборкой

1. Настоящий телефон не был подключён. Пакетный Unity оставляет `Screen=640×480` даже при запросе 720×1280, поэтому фактическую компоновку гардероба, безопасные отступы, принудительный поворот экрана и FPS на устройстве эти прогоны **не подтверждают**. Книжные кадры проверяют арт и модельный масштаб, но не реальную геометрию UI устройства.
2. Проверка успешного ввода секретного промокода пропущена, так как `DOODLIK_TEST_PROMO_CODE` не задана. Отказ неверному коду, сохранения, скрытие эксклюзивов и миграции проверены.
3. Для будущих обновлений Android нужен постоянный собственный ключ подписи: сейчас `AndroidKeystoreName` не задан. Идентификаторы приложения и прежнюю подпись после публикации менять нельзя без последствий для обновлений и данных.
4. Скрипт сборки всё ещё жёстко задаёт `0.0.1`, а Android version code сейчас `1`. Перед следующей версией их нужно повышать осознанно. На этом этапе версию не меняли.
5. Editor target-проверки не равны реальной APK/EXE-сборке и не измеряют производительность устройства. После ручной проверки в Unity нужен отдельный smoke-test готовых сборок.
6. Unity 6000.5 сообщает предупреждения об устаревших API (в том числе поиске объектов и старых Editor-вызовах). Они не мешают компиляции, но перед следующим крупным обновлением их стоит убрать.

Проект не коммитился и не очищался: существующие незавершённые изменения пользователя сохранены.
