# Doodlik 0.0.2 — тестовый выпуск

Статус: Windows EXE и Android APK 0.0.2 собраны и упакованы в `Desktop/Doodlik/v0.0.2`. Работающий Unity-проект и сохранения игрока не использовались для автоматических проверок; прогоны проведены в отдельной копии `.utmp` без звука.

## Уже подготовлено

- `PlayerSettings.bundleVersion = 0.0.2`, `AndroidBundleVersionCode = 2`; Android ID основной игры оставлен `com.tokyoghoul.doodlik`.
- Меню сборки берёт версию из Player Settings, а не возвращает её к 0.0.1. Команда Android Test APK использует отдельный `com.tokyoghoul.doodlik.test` и Development-сборку с тестовой админ-панелью; после операции прежние настройки проекта восстанавливаются.
- В Build Settings включена игровая сцена `Assets/Scenes/SampleScene.unity`. Состав пакетов и игровые ресурсы не менялись ради версии.

## Автоматическая проверка 05.10.2026

- Изолированный Unity 6000.5.2f1 без звука: проверки генерации мира и маршрута, реальной физики прыжка, столкновений, смерти/рестарта, меню, звука, гардероба и сохранений прошли на Windows- и Android-профилях. Код и игровые ресурсы QA-копии сверены с основным проектом.
- 24 повторяемых контрольных забега генератора до 1000 очков (четыре зерна для каждого сочетания формата и управления): **39–47 ловушек за забег**, считая крупные препятствия и локальные шипы. Горизонтальные ветки, вертикальные лозы, летающие семена и локальные шипы встретились в каждом забеге. Стартовые 200 очков не остаются совсем пустыми.
- Те же 24 фиксированных сочетания зерна, формата и управления проверены до 5000 очков: на отрезке 4000–5000 в среднем **60–80 ловушек** против **40–46** на первых 1000. Наибольший короткий участок — 20 ловушек за 200 очков. Проверка ограничивает и рост, и перегрузку во всех режимах ПК/телефона.
- Проверки не являются прохождением человеком: субъективная сложность, удобство управления и видимость ловушек на настоящем телефоне пока не подтверждены. В книжном режиме с инерцией первые 200 очков в отдельных зернах дают лишь 1–3 ловушки, затем их становится больше; стоит оценить именно это начало.
- Покадровый планировщик ловушек прошёл проверки корректности, но в headless Editor диагностированы отдельные порции до 15 мс при целевом бюджете 0,65 мс. Это **не замер FPS телефона** и не повод объявлять производительность проверенной: после разрешения на сборку нужен профиль на устройстве.
- Play Mode-проверка столкновений, щита, паузы, поражения и перезапуска прошла. В её headless-логе Unity SearchDatabase однажды выдал ошибку фонового индексатора на старте; стек не содержит игровых скриптов. Это отдельный вопрос редактора, не подтверждение ошибки в игре.
- Успешный ввод секретного промокода не прогоняли автоматически без значения `DOODLIK_TEST_PROMO_CODE`; проверены неверный код, перенос и сохранение прогресса. При ручной проверке использовать секрет без записи в общий лог/скриншоты.

## Сборка 06.10.2026

- Windows x64: Unity `BuildReleases.BuildAll` завершил сборку, размер по отчёту — 210 105 784 байта.
- Android arm64: Unity подготовил Gradle-проект, но встроенный запуск Gradle на этой машине дважды остановился с `Unable to establish loopback connection`. Тот же Gradle-проект собран напрямую с локальной настройкой Java `jdk.net.unixdomain.tmpdir`; `assembleRelease` завершился успешно. APK имеет пакет `com.tokyoghoul.doodlik`, версию `0.0.2`, код версии `2`, min SDK `26`, target SDK `36` и ту же SHA-256 подписи, что APK 0.0.1.
- RAR-архив содержит папку Windows-сборки, APK и TXT-патчноут. Служебные каталоги `DoNotShip` исключены; тест целостности RAR прошёл.

## Что нужно проверить вручную перед распространением

1. В Unity сыграть обычные попытки на ПК и в Android-профиле: альбомный/книжный экран, точное управление/инерция. Оценить плавное увеличение плотности от луга до космоса без ощущения перегруза; особенно проверить спокойный старт в книжном режиме с инерцией.
2. Проверить дальние и точные прыжки без бонусов; колючие ветки и локальные шипы (последние — примерно после 500 очков), полёт семян, прыжок с куста, щит и отсутствие смерти от визуально пустого места.
3. Проверить меню, отдельные ползунки звука, монеты/усиления, гардероб (включая несколько аксессуаров и шлем с другим котиком), поражение и перезапуск. Убедиться, что рекорд, покупки и достижения сохраняются.
4. Перед публикацией в магазине решить вопрос постоянного ключа подписи. Сейчас `AndroidKeystoreName` пуст: APK 0.0.2 подписан тем же отладочным ключом, что и 0.0.1, но переход на другой ключ позднее может помешать обновлению поверх этой установки.
5. Провести smoke-test APK на настоящем телефоне: касания, поворот, вырезы/безопасные поля, звук, нагрев/FPS, установка поверх предыдущей версии с сохранением данных. EXE проверить на ПК отдельно; автоматический запуск EXE не проводился, чтобы не затронуть локальные сохранения игрока.

Автоматические тесты не заменяют субъективную оценку сложности человеком и не доказывают отсутствие любого возможного бага. Сборка и проверка файлов завершены; проверка реального устройства и человеческое прохождение остаются открытыми.
